
# AI Personal Assistant LLM 🤖

A multilingual AI personal assistant built with Python, Streamlit, and Hugging Face Transformers.

## Features

- Local AI model using Qwen2.5-0.5B-Instruct
- Persistent personal memory using JSON
- Chat history saved locally in JSON
- English and Roman Urdu conversations
- Streamlit user interface

## Technologies

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- JSON

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/maria3t378-ai/AI-Personal-Assistant-LLM.git
   ```

2. Open the project folder:

   ```bash
   cd AI-Personal-Assistant-LLM
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   streamlit run app.py
   ```

The model may download the required files on its first run.

## Privacy

Personal memory and chat history are stored locally and are excluded from Git tracking.
